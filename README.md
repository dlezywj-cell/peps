# peps

估值透视：保留 A 股、港股、美股的数据源、PE/PS、FW1/FW2、财务补录、历史记录、图表缩放及 GitHub 同步，增加日本、韩国和台湾普通股票。

| 市场 | 输入示例 | 金额币种 |
| --- | --- | --- |
| 日本东京市场 | `7203.T`（丰田）、`6758.T`（索尼） | JPY / 日元 |
| 韩国 KOSPI | `005930.KS`（三星电子） | KRW / 韩元 |
| 韩国 KOSDAQ | `247540.KQ` | KRW / 韩元 |
| 台湾上市 | `2330.TW`（台积电） | TWD / 新台币 |
| 台湾上柜 | `6488.TWO`（环球晶） | TWD / 新台币 |

完整后缀可在自动模式直接搜索；纯数字代码须先选市场。名称搜索使用 Yahoo 的名称索引，英文/当地语言名称及完整代码更可靠。多个匹配结果由用户选择。新增市场不包含 ETF、指数或日本地方交易所。

所有收入、净利润和预测录入均以**亿交易货币**为单位（例如台湾为亿新台币），股本补录为亿股。新股票使用完整符号作为本地及云端记录键，保留原 A/港/美股数据键。

### 启动完整版本

需要 Node.js 22 或更高版本，无额外依赖：

```sh
node server.mjs
```

访问终端输出的本地地址。网页自动使用同源的 `/api/international` 数据服务。默认仅监听本机；部署到服务器时可设置 `HOST`、`PORT` 和逗号分隔的 `ALLOWED_ORIGINS`。对外部署须由托管环境提供 HTTPS。

### GitHub Pages 上线新增市场

GitHub Pages 仅托管静态文件，无法直接转发 Yahoo 请求。免费公共代理会限流或失效，不能作为稳定上线的保证。页面提供公共代理备用路由，但建议部署随附的轻量服务：

1. 在 `worker` 目录使用 Cloudflare Workers 部署：`npx wrangler deploy`，按提示登录自己的 Cloudflare 账号。部署使用该账号的 Workers 配额。
2. 如网页使用自定义域名，在 `worker/wrangler.toml` 的 `ALLOWED_ORIGINS` 加入实际页面 origin。
3. 在页面右上角设置中填写部署返回的完整 HTTPS 服务地址并保存。此地址仅保存在当前设备，不随 GitHub Token 同步；新设备需配置一次。

服务只允许三个公开 Yahoo 查询接口，固定日线粒度和财报字段；不接收财务补录数据、不转发 GitHub Token，不需要将密钥写入页面。Workers 对成功日线/搜索缓存 15 分钟、财报缓存 6 小时；失败结果不缓存。行情并非实时保证，仍取决于上游覆盖和可用性。

### 数据口径与边界

- Yahoo 年度财报通常只提供近四年，季度股本通常只有近五期。更早财报继续使用原有补录流程；不能保证所有股票的全部历史年份都有自动财报。
- 日线使用明确起止时间戳，避免 Yahoo `range=max` 自动降为月线；交易日按交易所时区解析。当前实现的最早查询时间为 1970 年。
- 收盘价使用 Yahoo 拆股调整后的 `close`，不使用扣除现金分红的 `adjclose`。其财务时间序列普通股股本也已追溯调整，不能再按拆股事件重复调整。
- 有财报时优先匹配期末股本，缺失时沿用最近披露股本估算。新市场股本完全缺失会要求补录，不会套用默认一亿股。
- 不同财报币种必须先换算成交易币种；币种不明或汇率缺失的报告进入补录流程，防止生成混合币种 PE/PS。
- 非自然年度沿用原逻辑：一季度结束的财年映射到前一价格年度。本工具仍是年度回看估值，不是按财报公告日构造的无前视回测。
