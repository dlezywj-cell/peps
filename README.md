# peps

股票历史 PE / PS 估值图表。

## A 股估值口径

- 历史市值 = 当日未复权收盘价 × 当日已生效总股本。
- 腾讯主行情和东方财富备用行情均使用未复权价格；不混入 Yahoo 的拆股调整价。
- 股本使用东方财富 `RPT_F10_EH_EQUITY` 的 `END_DATE` / `TOTAL_SHARES`，只采用交易日当天或此前最近生效的记录，保留真实送转股、增发等变化。
- 缺少有效历史股本的日期，市值及 PE / PS 留空；不以未来股本、当前股本或 EPS 反推值冒充当日股本。
- 财务分母沿用原有年度及手工预测逻辑；尚未披露的完整年度可补录预测，取消补录则对应年度估值留空。

前复权价格受后续现金分红影响，早期可能接近零，不适合直接乘当时股本计算历史市值。紫金矿业 2016-01-27 / 28 的原始收盘价为 2.87 / 2.71 元，而排查时前复权价格为 0.29 / 0.13 元，旧的相邻倍数校验因此误判拆股并拒绝整个区间。A 股现在直接按实际价格与有效股本配对计算，真实送转股也无需猜测性价格修补。港美股原有拆股调整流程保持原有口径。

## 前瞻年度口径（FW1 / FW2 / FW3）

- FW1 = 最近一个已披露年报年份的下一年，即当前尚未走完的年度；FW2 = 再下一年；FW3 = 第三年。
- 三个年度统一在「业绩录入」弹窗录入，每行填的是该年度自身的收入与净利润，与图表上按交易日展开的 FW1 / FW2 / FW3 曲线口径一致。
- 每个交易日都有自己的 FW1 / FW2 / FW3：分别取该交易日所在年度、次一年、第三年的财务数据；已披露年报优先，其次录入数据。历史的 FW3 会自然回落到当年已披露的年报。
- 存储沿用原分层：FW1 走手工层（与原缺报补录同一份数据），FW2 / FW3 走预测层；每次修改按天留下历史记录，原样保存不会产生历史噪音。
- 缺数据的年份**一律不自动弹出补录窗口**：对应曲线直接留空，计算完成时只用一行文字说明哪些年份缺数据。需要补录时从「业绩录入」里按需进入；历史年份缺真实财报的补录入口也只在该弹窗里出现。
- 财务数据图的 tooltip 每行只给「年份 + 数值 + 同比」，形如 `FW1 收入 2025: 1,500 亿  yoy +25.0%`。FW1 比上一年实际数，FW2 比 FW1，FW3 比 FW2；缺少可比基数时不显示同比段。Chart.js 的 tooltip 回调只能返回字符串，不要返回对象，否则会渲染成 `[object Object]`。
- 估值图图例**按条切换**：点某一条线只显示或隐藏这一条，FW1 / FW2 / FW3 之间互不牵连，PE 与 PS 也可以单独收起。某根轴上的线全部隐藏时该轴自动收起，重新点开任意一条后自动回来；轴的上下界始终按当前可见数据重算。

## 回归验证

运行 `node --test tests/*.test.cjs`。`a-share-valuation.test.cjs` 覆盖紫金低基数误判、真实拆股前后市值连续、股本生效日、缺失数据、分页失败和备用源价格口径；`us-fiscal-year.test.cjs` 覆盖美股跨年财年；`forward-estimates.test.cjs` 覆盖 FW1 / FW2 / FW3 的年度口径、估值字段、录入弹窗三行结构与保存分层；`valuation-legend.test.cjs` 覆盖图例按条切换、PE 与 PS 互不牵连、轴自动收起与恢复。
